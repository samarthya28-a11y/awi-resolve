AWI Resolve — Automated IT Support
==================================

TO INSTALL
  1. Double-click "Install AWI Resolve.cmd".
  2. Click "Yes" on the Windows permission prompt (this lets the support agent
     apply fixes when you approve them).
  3. That's it. A shortcut called "AWI Resolve Support" appears on your Desktop
     and Start Menu.

TO GET HELP
  Open "AWI Resolve Support" and describe your problem. The AI technician will
  investigate and ask your permission before changing anything.

TO REMOVE
  Right-click "Uninstall.ps1" -> Run with PowerShell (or run it from the install
  folder at C:\Program Files\AWI Resolve), and click "Yes".

WHAT'S INCLUDED
  Everything needed to run — you do NOT need to install Node.js or anything else.

SETTINGS (advanced)
  config.json controls which support service the agent connects to. Leave it as-is
  for the local demo.
